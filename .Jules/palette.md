## 2024-08-24 - Accessible Names for Pagination and Modal Controls
**Learning:** Found that custom-built modal 'X' buttons lacked accessible names (e.g. `aria-label="Fechar"`), meaning they could be announced ambiguously by screen readers. Pagination controls were also built using standard `<button>`s without a `<nav>` container or explicit screen-reader cues for next/previous actions and current page state (`aria-current="page"`). Additionally, the Bottom Navigation bar used `role="tablist"` on the container but lacked `role="tab"` and `aria-selected` on its child items.
**Action:** When creating standard UI patterns like modals, pagination, or tabbed navigation from scratch (without a library), ensure basic WAI-ARIA roles, states, and labels (e.g. `aria-current`, `aria-label`, `role="tab"`) are provided so the semantic meaning is preserved for assistive tech.
